# Lifestyle for Lifetime™ website

A responsive one-page static website based on the public content and themes from:
https://site-xhu01z2gr.godaddysites.com/

## Files
- `index.html` — page structure/content
- `styles.css` — responsive styling
- `script.js` — mobile navigation, footer year, and contact mailto helper

## Run locally
Open `index.html` in a browser.

For a local development server:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Notes
- The contact form is front-end only and opens the visitor's default email application.
- To collect submissions directly, connect the form to Formspree, Netlify Forms, a serverless function, or your own backend.
- Replace or extend any text and imagery as needed.
